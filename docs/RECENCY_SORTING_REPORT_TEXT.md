# 报告可用文字：时效性排序

在排序阶段，系统不仅考虑 query 与 document 的余弦相似度，还引入了文档发表年份的时效性因素。科研成果检索中，较新的成果通常具有更高的参考价值，因此在相关性接近的情况下，系统会适当提升较新成果的排名。

系统最终排序分值定义为：

\[
final\_score(d)=0.85\times cosine(q,d)+0.15\times recency(d)
\]

其中，\(cosine(q,d)\) 表示 query 与 document 的余弦相似度，\(recency(d)\) 表示文档的时效性分数。时效性分数定义为：

\[
recency(d)=\frac{1}{1+current\_year-year(d)}
\]

本系统当前年份取 2026。若文档年份为 2026，则时效性分数为 1；若文档年份为 2025，则时效性分数为 0.5；若文档年份为 2024，则时效性分数约为 0.333。年份越早，时效性分数越低。该设计保证了余弦相似度仍然是排序的主要依据，同时让较新的科研成果在相关性接近时具有一定优势。

代码实现位于 `search_engine.py` 文件中。系统首先计算 query 与候选 document 的余弦相似度 `cosine_score`，然后调用 `_recency_score()` 根据文档年份计算 `recency_score`，最后得到 `final_score`。前端页面会同时显示综合分值、余弦相似度和时效性分值，便于验证排序优化确实生效。
